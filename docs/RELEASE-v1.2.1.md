# LingoDesk 1.2.1

- Removed the bottom-right resize arrow from floating captions. Drag any of the four corners to resize the window.
- Floating captions now tuck off-screen when dragged to either side, leaving a narrow tab. Tap the tab to restore the window.
- Added a LecSync console link in Settings that opens the console in your default browser.
- Fixed floating-window cleanup to prevent duplicate or invisible windows from remaining after closing.
