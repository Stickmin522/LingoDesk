# LingoDesk 1.2.1

## App updates

- The version shown in the app's Settings screen now displays 1.2.1.

Recording, speech recognition, translation and meeting-note behavior remain the same as in 1.2.0.

## App improvements included from 1.2.0

- Choose any two different languages from 60 supported languages, with automatic translation in both directions.
- Separate language selectors prevent choosing the same language on both sides.
- Floating captions appear only during an active session after leaving the app.
- Choose from 60 interface languages or follow the system language, with English fallback and right-to-left text support.

## Download

Download `lingodesk-1.2.1-arm64.apk` below. Requires Android 10 or later and an ARM64 device.

The matching source is included in `lingodesk-1.2.1-source.zip`. `SHA256SUMS.txt` provides checksums for both downloads.

**Installation note:** This APK uses a different signing key from the previous published APK. It cannot update that installation in place. Export recordings you want to keep before reinstalling.
